# 选片短视频打卡常见阻碍与恢复速查

| 环节 | 常见现象 | 标准恢复动作 |
|---|---|---|
| **ERP 查表** | 旧页面缓存未切到目标日期 / 登录态失效 | 同一浏览器会话刷新一次并核对**报表标题日期**与目标日一致；需验证码时交接用户，查表失败保留待办不误判为空表。 |
| **底片匹配** | 问号改期 / 成长套多轮 / 重拍备注 | 问号改期排除；成长套排除已完成历史轮次；明确整轮重拍只取最后一次实际完成拍摄；同名多目录无法区分时 `block` 本单先做下一单。 |
| **修后照片提取** | 既有原片又有「已修 / 魔镜修图」子目录 | 仅在本机工作副本操作：有明确修后目录时**只从修后照片挑选**（修后不足 25 张时暂停询问）；同名不同内容加 `_已修` 区分，绝不改 NAS 源目录。 |
| **复制与导出慢** | 大目录复制或剪映导出耗时较长 | 比较字节数增量、槽位推进与导出状态区分“缓慢”与“停滞”；连续两次间隔约 1 分钟无任何进展再查挂载或弹窗，原进程仍在推进时绝不盲目重开。 |
| **剪映重启/切窗** | 会话中断或焦点切走 | 重新定位原工作副本并核对最后成功槽位，从下一槽接续；绝不重复创建副本或批量清空最近删除。 |
| **模型额度耗尽** | 云端定时任务中途额度用完 | 以已落盘的 `queue.db` 与单客断点为准，等待下次触发额度恢复后自动 `next` 接续旧单，再跑新日期。 |
