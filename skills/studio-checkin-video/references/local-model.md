# 局域网模型执行（可选 Ollama 模式）

服务地址、端口、模型名、digest、超时及运行路径从仓库外的 `StudioData/config/ollama-connection.json` 读取，不写进技能包。模型切换不改变拍摄日期判定、修后照片优先、25 张保留与 22 张上片、原 NAS 归档及草稿清理规则。

## 连接与能力核验

- 先只读查询 Ollama 的 `/api/tags` 与 `/api/show`，核对已安装的文字与视觉模型。照片仅发送去除 EXIF 的预览缩略图；禁用代理和重定向，不静默回退到其他端点。
- 模型不可达、输出截断或能力不符时保留已完成断点；恢复后核对输入哈希与断点，只续跑未完成部分，不重放复制或剪映动作。

## 审阅与名单锁定流程

1. 用 `studio-photo-selection` 的 `scripts/ollama_assess.py` 完整审阅候选照片并保存逐张断点。
2. 视觉模型审阅带编号联系表，归纳场景、姿势、人物数和近似重复组，对拟入选照片放大复核全员眼神与表情。
3. 锁定 25 张保留名单及其 22 张视频子集（优先 1–2 张全家福，合照总数 ≤ 3 张，成人单人照不入选）；仅将已锁定名单对应的 Assessment 传给 `SelectionTool.execute` 校验张数、近似组和子集关系，严禁让脚本从全量候选中重新选片。
