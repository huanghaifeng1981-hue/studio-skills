# 已有草稿与断点续跑

version: 26.10.8

## 继续已有草稿的优先原则

用户已经认可草稿效果时，不重新套模板。

执行顺序：

```text
找到已有草稿
→ 创建或确认工作副本
→ 核对已完成位置
→ 从下一未完成位置继续
→ 确认替换操作完成
→ 导出
→ 确认落盘，待用户人工验收
→ 按 [草稿清理规则](../SKILL.md#短视频打卡完成后清理草稿) 处理本次副本
```

## 逐位替换

当批量替换不可用或不稳定时：

1. 选择目标照片片段；
2. 使用剪映当前提供的“替换片段”；
3. 选中对应照片；
4. 如有“复用原视频效果”，保持开启；
5. 替换后读取界面状态，确认提交完成；默认不另做缩略图、构图或时长质检；
6. 确认替换提交后才记录该位置已完成；尚在替换预览的槽位记为 pending。按 [efficient-execution.md](efficient-execution.md) 保存每段断点并控制截图回传。

## 缺失素材

旧素材缺失时：

- 不把新文件强行改名冒充旧素材；
- 不仅凭缓存缩略图判断素材完整；
- 必须确认真实导出文件存在且非零；默认质量由用户人工验收。

## 恢复

状态区分：

```text
pending
replaced
exported-awaiting-user-review  # 默认制作完成，质量待用户检查
visual-checked                # 仅实际执行视觉质检后
export-verified               # 仅实际通过所要求质检后
```

默认模式以 `exported-awaiting-user-review` 代表制作完成；不会因尚未人工验收而重复制作或阻断下一批。
