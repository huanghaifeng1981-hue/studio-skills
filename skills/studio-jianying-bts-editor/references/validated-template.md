# 已验证模板与录屏依据

version: 26.10.3

## 模板参考

已验证示范模板：

```text
名称：萌娃超可爱卡点
画幅：9:16
时长：约 21 秒
替换位：22
参考文字：整个地球 / 你最可爱
风格：暖色、白色拍摄框
```

## 已验证关键动作

录屏与实际测试共同确认过：

1. 从收藏模板进入时间线；
2. 导入 22 张照片；
3. 展开待替换素材位；
4. 多选素材并拖到首个替换位；
5. 等待模板重建；
6. 检查全部位置；
7. 本地导出。

## 已验证导出基线（2026-10-02 实测）

```text
MP4
H.264
1440×2560
24fps
Rec.709 SDR
约 21.125 秒
```

## 当前默认导出参数（2026-10-08 更新）

```text
MP4
H.264
1080×1920
30fps
Rec.709 SDR
约 21.1 秒
```

说明：1080×1920 / 30fps 由用户于 2026-10-08 指定为默认导出参数，替代原 2K/24fps 基线。
2026-10-09 已在本机端到端验证：10 批素材各完成 22 位替换并导出，成片解析 moov 实测 1080×1920、30.0fps、21.133 秒，首/中/尾帧无黑屏空白。
实现方式：把工作草稿的「草稿帧率」设为 30、分辨率设为 1080×1920，导出面板默认值随之正确（详见 ui-automation-notes.md 第 3 节）。

## 边界

以下内容没有作为长期默认规则：

- 录屏中的个人路径；
- 日期草稿名；
- 具体鼠标坐标；
- 某台机器的固定应用路径；
- 云备份；
- 独立 MP3 导出；
- 60 秒等未经用户确认的时长默认值（1080×1920/30fps 自 2026-10-08 起由用户指定为默认，见上节）。

模板稳定 ID / 链接未固定，所以新环境中仍需通过名称、封面、22 个替换位共同核对。
