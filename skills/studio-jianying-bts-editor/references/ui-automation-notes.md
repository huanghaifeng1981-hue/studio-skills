# 剪映界面自动化的已知陷阱与对策

version: 26.10.10

本文记录在 macOS 剪映专业版上实测遇到的界面自动化问题与验证过的对策。
不绑定具体操作工具；文中尺寸/坐标为实测值，换机器、换版本或换窗口布局后需重新核对。

## 1. 窗口尺寸会在「首页」与「编辑页」之间变化

剪映主窗口在两种状态尺寸不同（实测）：

```text
首页窗口     1168 × 744
编辑器窗口   1508 × 865
```

后果：如果操作服务是在「首页尺寸」时建立窗口几何的，之后进入编辑器（窗口变大），
坐标点击会整体错位，报「找不到窗口 / windowNotFoundAtPosition」这类错误；
但**同一窗口内的元素定位点击和键盘操作仍然正常**。

判别：坐标点击全部失败、而元素点击与键盘可用时，先怀疑窗口几何过期，而不是目标本身不可点。

对策（按顺序）：

1. 让应用停在**目标尺寸的那个界面**（要操作编辑器，就先打开草稿、停在编辑器）；
2. 重新获取目标应用/窗口并读取截图刷新几何；不自动重启操作服务或用户应用；
3. 恢复后先做一次点击自检（例如点一下时间线空白处），确认可用再进入正式流程。

注意：每次「首页 ↔ 编辑器」往返都可能再次失效。因此：

- 能不进首页就不进；一批做完再进出一次；
- 每次进出后都先做一次点击自检；
- 不要把「刚才点成功了」当作后续所有坐标都可用。

## 2. 部分下拉菜单无法用元素或坐标操作

实测剪映导出面板的「分辨率」「帧率」下拉：

- 菜单在无障碍树中被合并成**一个文本节点**
  （形如 `Value: 24 fps 25 fps 29.97 fps 30 fps 50 fps …`），没有可单独点击的项；
- 按坐标点击菜单项：点击落到父窗口坐标系，结果只是**关掉菜单、不改变取值**；
- 键盘上下键、回车、空格、滚轮均无反应。

结论：**不要在这种控件上反复尝试**。改用下面两条：

1. **优先改草稿参数，让默认值正确**（见第 3 节）——设置一次，所有批次受益；
2. 无法改草稿参数时，请人工设置一次，然后**在同一个面板会话内立即导出**；
   关掉面板会丢失该次选择。

## 3. 导出参数默认跟随草稿，面板上的改动不持久

实测（剪映专业版）：

- 导出面板的「帧率」默认值 = **草稿帧率**。在面板里改成别的值，关掉面板即失效，
  下次打开又回到草稿帧率。面板自带提示：「默认使用草稿帧率，修改可能导致预览和导出画面有差异」。
- 导出面板的「分辨率」可选「原始」，即**草稿尺寸**。

所以要让成片长期按某个帧率/分辨率输出，正确做法是**改草稿参数**：

```text
草稿参数 → 修改 → 比例 / 分辨率 / 草稿帧率 → 保存
```

工作副本会继承母版的草稿参数，因此：

- 只要把**母版**（或一份被当作源的工作副本）的草稿帧率/分辨率设成目标值，
  之后所有副本天生就是该参数，导出面板默认值也随之正确，无需每次人工改；
- 改草稿帧率会把时间线重采样到新帧率，**切点时间码(HH:MM:SS:FF)随之改变**，
  之前记录的时间码基线必须按新帧率重新核对；片段时长（秒）不变；
- 改草稿分辨率（如 2K → 1080×1920）会按同画幅缩放画布，构图比例不变。

## 4. 模态弹窗与提示的关闭方式

实测以下弹窗**按元素点击无效**，需要别的关闭方式：

| 弹窗 | 关闭方式 |
|---|---|
| 「文件已存在，是否覆盖？」 | 点「取消」，回到导出设置核对目标路径。 |
| 「导出成功」（发布页） | 确认 MP4 非空后，点「发布」旁边的灰色「关闭」，确认返回编辑窗口。 |

通用做法：

- 弹窗出现后先读无障碍文本，拿到按钮清单；
- 元素点击无效时，重新读当前截图，按按钮文字定位；无法确认按钮或自动审核拒绝操作时，保留断点并请用户关闭弹窗。

导出成功后可能延迟弹出「导出成功」提示，会挡住后续操作；进入下一步前先检查并关掉它。

2026-10-27 补充：导出按钮、移入最近删除确认按钮曾出现 AX 元素点击后界面不变。读取当前截图后直接用可见按钮坐标提交一次，不继续反复尝试同一元素点击。草稿中文重命名使用 `app.paste`，本机 `typeText` 曾丢失中文字符；提交后按实际界面名称记账。导出路径区域是目录选择入口，点击会打开文件选择器，不能当作可直接输入的文本框；先读新界面，再通过“前往文件夹”选择目录。导出标题粘贴后从 AX 的完整输出路径核对中文文件名。

## 5. 对话框尺寸会短暂处于中间态

替换片段这类对话框是动态生成的，刚出现时截图尺寸可能是中间值
（实测见过 396×326，稳定后为 724×596）。

对策：先核对当前截图与控件。只有观察到尺寸处于中间态时才再次读取，稳定后继续；不要固定连续读取 3–5 次。无法稳定则按失败处理停止该段，不盲点。

## 6. 导出完成判定

- 「导出中」与「导出完成」是两个不同界面；完成页会出现「打开文件夹 / 关闭」等按钮。
- 判定完成应使用**稳定特征**（例如完成页固定位置的按钮颜色、或固定按钮文本），
  不能仅凭进度 100% 或模型返回的 `export_complete` 标签。
- 完成页优先点「发布」旁边的灰色「关闭」。观察到编辑窗口后继续批次流程。


## 7. SMB 照片路径与 macOS 文件选择器（26.10.5）

### 先确定文件在哪，再操作界面

- `smb://主机/共享/子目录` 是网络地址，不是文件选择器可直接使用的本地文件路径。
- 用当前挂载信息核对服务器、共享与子目录，不能只根据卷名猜路径。共享根目录与共享子目录可能分别挂载；系统也可能添加卷名后缀。
- 在用户授权目录内枚举各客片的 `123`，验证目标文件可读、大小非零。文件已存在但 UI 导航失败时，记录“选择器导航失败”，不要报告“照片不存在”。
- 每批保留 slot → 原始绝对路径 → 实际导入路径映射。按拍摄顺序时优先核对可用拍摄时间；以相机文件序号代替时说明依据，跨相机或编号回绕不能混排。
- NAS 不稳定或路径过长时，可复制已选照片到当前工作区内的短路径目录；保留映射并核对复制大小。不要擅自重命名原片。工作副本仍是草稿依赖；成片达到当前模式的导出交付标准后先按 SKILL.md 第 8.1 节清理工作草稿，再确认没有剩余依赖并清理临时照片副本。导出未完成或要求保留编辑草稿时不要清理。

### 文件选择器按状态推进

1. 打开剪映的导入或替换文件选择器，读取当前界面，确认标题、文件列表和取消/导入按钮。
2. 按一次 `super+shift+g` 后立即读取界面，确认出现 `PathTextField`。尚未出现时不要输入路径。
3. 使用新读取的字段索引设置完整本地绝对路径；或聚焦字段、全选后粘贴。读取字段值并与目标路径逐字核对。不要用逐字符快速输入长路径，也不要在未确认焦点时发送路径。
4. 字段值正确后只按一次 Return，再读取界面。只有“前往”浮层关闭、文件列表定位到正确目录/文件才算导航成功。若仍在 `PathTextField`，不得再次盲按 Return。
5. 核对选中文件的名称与路径，确认“导入”按钮可用，再点击最新索引的“导入”。导航确认和导入确认是两个独立状态，不能用连续两次 Return 代替。
6. 如出现替换预览，确认已选文件与“复用原视频效果”选项，提交替换后读取编辑器状态确认操作完成。默认不另做照片或缩略图视觉质检。

所有动作使用当前可用的 UI 工具；在 cua_repl 中每次改变状态后读取 AX，再决定下一步。不要把打开浮层、输入长路径和连续确认封装成不检查状态的按键串。索引只能从最新 AX 中获取；坐标需有当前截图依据。

### 恢复顺序与停止条件

- 路径变成 `/`、缺少开头或浮层未关闭：先保存当前界面证据，检查输入焦点及字段完整值；这不证明源文件缺失。
- 若完整文件路径不能导航，取消“前往”浮层，确认返回文件列表，再尝试只输入已验证的父目录；在列表中按确切文件名选择照片。每次 Escape 后都核对状态，避免误关整个选择器。
- 文件目录列表可见时，优先直接选择文件，不重复打开“前往”。
- 如坐标整体失效，重新获取目标应用/窗口并读取截图核对几何；不要擅自重启用户应用或操作服务。
- 同一步失败两次，刷新状态并尝试上述一种有依据的替代方案；仍失败才停止该步骤。记录失败发生在挂载、文件读取、路径字段、导航或导入的哪一层，以及已完成素材位，不把 UI 失败归因于文件不存在。

### 验证范围

上述修订来自 2026-10-23 的真实故障：文件实际存在，首次替换成功，后续长路径输入/确认未完成。输入和确认之间缺少状态核对是已观察到的流程缺陷；是否还存在窗口焦点或工具异步行为，需要现场验证。本文不是已通过 11 批端到端导出的声明。
