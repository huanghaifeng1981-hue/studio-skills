# 中文技能名称

## 1. 用途与交付

- **适用场景**：说明何时使用、何时不使用。
- **必要输入**：调用方需提供的文件、日期或参数。
- **交付产物**：最终输出的文件格式、保存位置及核对标准。

## 2. 环境、配置与边界

- **支持平台**：明确已实测通过的系统（如 `macOS 已验证，Windows 待验证`）及外部软件依赖。
- **外部配置**：配置文件、模型与中间产物统一放在仓库外的 `StudioData/`（通过 `--config` 或环境变量 `STUDIO_DATA_DIR` 传入），包内不存真实路径或密钥。
- **操作授权**：明确哪些动作只读、哪些动作（如发消息、覆盖、删除）需人工确认后执行。

## 3. 执行步骤

1. 按顺序列出确定性脚本调用与模型判断分工。
2. 精确计算、比对、搬运走包内 `scripts/`；审美或语义归纳按需调用具备对应能力的模型。

## 4. 验收与异常恢复

- **完成标准**：可观察、可核对的验收条件（如数量、金额、哈希、画面检查点）。
- **中断恢复**：失败时保留已完成进度与断点说明，重跑前先检查已有结果，避免重复副作用。
